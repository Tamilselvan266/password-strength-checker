# password-strength-checker

##  Project Overview
Weak passwords are one of the main reasons for data breaches and unauthorized access.  
This Password Strength Checker is a Python-based GUI application that analyzes user-entered passwords and determines their strength. It also provides suggestions to improve weak passwords.

This project is developed for educational and cybersecurity learning purposes.


##  Objectives
- To evaluate password strength (Weak / Medium / Strong)
- To encourage secure password practices
- To demonstrate regex-based validation
- To provide a simple and user-friendly GUI


## Technologies Used
- Python
- Tkinter (GUI)
- Regex (re module)


##  Password Strength Rules
The password strength is evaluated based on:
- Minimum length of 8 characters
- At least one uppercase letter (A–Z)
- At least one lowercase letter (a–z)
- At least one digit (0–9)
- At least one special character (@, #, $, %, etc.)


##  Features
- Graphical User Interface (GUI)
- Eye icon to show/hide password
- Password strength indicator
- Suggestions for improving weak passwords
- Clean and simple design


##  Application Flow
1. User enters a password
2. System analyzes the password using predefined rules
3. Strength result is displayed
4. Suggestions are shown if needed
